# Task 004: Extract i18n and add the Russian target for the Collections tab

> **Applied Skill:** AGENTS.md i18n Rules - `npm run i18n:extract` regenerates `projects/shared/src/locale/messages.xlf` (never hand-edited); every new `<trans-unit>` gets a Russian `<target>` in `projects/shared/src/locale/messages.ru.xlf` in the same change. `npm run i18n:check` is the gate.

## 1. Objective

Regenerate the source catalog after task 001 and add the Russian translation of the single NEW unit. Terminology: "пункт" for point.

**HARD RULE - do not change any EXISTING unit.** If a row's English source already has a `<trans-unit>` in `messages.ru.xlf`, leave it exactly as it is and add nothing. Never edit an existing `<target>`, never delete or reorder existing units. The diff of `messages.ru.xlf` must be additions only.

Requires task 001 (and tasks 002-003 so nothing else is pending).

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf` - **Action:** Regenerated by `npm run i18n:extract`
* **File Path:** `projects/shared/src/locale/messages.ru.xlf` - **Action:** Modify Existing File (append new unit only)

## 3. Code Implementation

**Step 1:**

```bash
npm run i18n:extract
```

**Step 2.** Find the unit with source `No collections or settlements in this period` in `messages.xlf`, copy its `id` and `<source>` verbatim and add to `messages.ru.xlf` directly before `</body>`:

```xml
      <trans-unit id="ID_FROM_MESSAGES_XLF" datatype="html">
        <source>No collections or settlements in this period</source>
        <target>Нет инкассаций и зачислений за этот период</target>
      </trans-unit>
```

| English source | Where | Russian target |
|---|---|---|
| `No collections or settlements in this period` | Labels.PointTransfersEmpty | `Нет инкассаций и зачислений за этот период` |

Every other string of the tab reuses an existing label (already translated): `Collections` ("Инкассации"), `Collect cash` ("Сдать в банк"), `Record settlement` ("Зачислить в банк"), hints, `Cash collections`, `Terminal settlements`, `This entry cannot be cancelled; a mistake is corrected by an adjustment.`, `Newest first`, `Oldest first`, `Movements could not be loaded`. Do not touch them.

**Step 3:**

```bash
npm run i18n:check
```

It must print `OK: <n> units translated`. Then run `git diff --stat projects/shared/src/locale/messages.ru.xlf` and confirm the diff only ADDS lines (no removed or changed lines); if any existing line was changed, revert it.

## 4. Validation Steps

Execute the following commands to ensure this task was successful. Do NOT run the full application server.

```bash
npm run i18n:extract
npm run i18n:check
npx ng build admin --configuration development
```
