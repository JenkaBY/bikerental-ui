# Task 012: Extract i18n and add Russian targets for the operator hand-in flow

> **Applied Skill:** AGENTS.md i18n Rules - `npm run i18n:extract` regenerates `projects/shared/src/locale/messages.xlf` (it writes only that file); every new `<trans-unit>` gets a Russian `<target>` in `projects/shared/src/locale/messages.ru.xlf` in the same change. Russian copy is consistent with the existing terms: "Сдать наличные" (hand in cash), "Касса" (cash drawer), "пункт" (point).

## 1. Objective

Seven NEW units (task 002). Everything else the flow shows is reused and already has a Russian target. `Labels.Done` shares its id with the existing `Done` -> `Готово` unit, so it adds NO unit: after extraction `Done` must appear exactly once in `messages.xlf`.

Existing units' targets MUST NOT change. The diff of `messages.ru.xlf` must be additions only (7 new `<trans-unit>` blocks, nothing modified or removed).

Requires tasks 002 and 007-011 (so extraction sees the final sources).

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf` - **Action:** Regenerated by `npm run i18n:extract`
* **File Path:** `projects/shared/src/locale/messages.ru.xlf` - **Action:** Modify Existing File

## 3. Code Implementation

**Step 1:**

```bash
npm run i18n:extract
```

**Step 2.** For each row, find the unit in `messages.xlf` by its English source and add to `messages.ru.xlf`, directly before `</body>`:

```xml
      <trans-unit id="ID_FROM_MESSAGES_XLF" datatype="html">
        <source>SOURCE_COPIED_VERBATIM</source>
        <target>RUSSIAN_TEXT</target>
      </trans-unit>
```

| English source (verbatim from `messages.xlf`) | Russian target |
|---|---|
| `Hand in cash?` | `Сдать наличные?` |
| `Instant and cannot be cancelled — if it was a mistake, an administrator corrects it` | `Операция проводится сразу и не может быть отменена — если это ошибка, администратор её исправит` |
| `Hand in` | `Сдать` |
| `Cash handed in` | `Наличные сданы` |
| `Time` | `Время` |
| `Remaining in drawer` | `Осталось в кассе` |
| `Hand in <x id="amount" equiv-text="amount"/>` | `Сдать <x id="amount" equiv-text="amount"/>` |

Use the ids and the exact `<x .../>` placeholder markup that `messages.xlf` shows (copy the source line character for character, the way the existing `Remaining: <x id="amount" equiv-text="amount"/>` unit is written in `messages.ru.xlf`); do not invent ids. Do not touch any existing unit (in particular `Done` -> `Готово`, `Cash drawer` -> `Касса`, `Bank account` -> `Банковский счёт`, `Hand in cash` -> `Сдать наличные`).

**Step 3:**

```bash
npm run i18n:check
```

It must print `OK: <n> units translated`. Then run `git diff --stat projects/shared/src/locale/messages.ru.xlf` and confirm only insertions (no deletions).

## 4. Validation Steps

Execute the following commands to ensure this task was successful. Do NOT run the full application server.

```bash
npm run i18n:extract
npm run i18n:check
npx ng build operator --configuration development
```
