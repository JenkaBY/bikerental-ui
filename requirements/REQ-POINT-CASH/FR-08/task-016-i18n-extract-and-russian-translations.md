# Task 016: Extract i18n and add Russian targets for shift closure

> **Applied Skill:** AGENTS.md i18n Rules - `npm run i18n:extract` regenerates `projects/shared/src/locale/messages.xlf` (it writes only that file); every new `<trans-unit>` gets a Russian `<target>` in `projects/shared/src/locale/messages.ru.xlf` in the same change. Terms consistent with existing copy: "пункт" (point), "Касса" (cash drawer screen), "Смена" (shift).

## 1. Objective

Thirteen NEW units (tasks 005 and 006). Reused entries already have Russian targets and must not be touched: `Close shift`, `Expected cash`, `Done`, `Back`, `Rental point`, `No shift is running`, `Maximum 2 decimal places allowed`, `Shift <x id="sequence" .../> · opened <x id="time" .../>`.

`This shift is already closed` is defined twice in the sources (`ErrorMessageCatalog` and `Labels.ShiftClosureAlreadyClosed`) but has identical text, so it is ONE unit.

Existing units' targets MUST NOT change. The diff of `messages.ru.xlf` must be additions only (13 new `<trans-unit>` blocks, nothing modified or removed). Requires tasks 005-015 (so extraction sees the final sources).

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf` - **Action:** Regenerated by `npm run i18n:extract`
* **File Path:** `projects/shared/src/locale/messages.ru.xlf` - **Action:** Modify Existing File

## 3. Code Implementation

**Step 1:**

```bash
npm run i18n:extract
```

**Step 2.** For each row, find the unit in `messages.xlf` by its English source and add to `messages.ru.xlf`, directly before `</body>`:

```xml
      <trans-unit id="ID_FROM_MESSAGES_XLF" datatype="html">
        <source>SOURCE_COPIED_VERBATIM</source>
        <target>RUSSIAN_TEXT</target>
      </trans-unit>
```

| English source (verbatim from `messages.xlf`) | Russian target |
|---|---|
| `Shift` | `Смена` |
| `Close shift?` | `Закрыть смену?` |
| `Counted amount` | `Пересчитано` |
| `Difference` | `Разница` |
| `Matches` | `Совпадает` |
| `A closed shift cannot be reopened` | `Закрытую смену нельзя открыть снова` |
| `Closed at` | `Закрыта в` |
| `This shift is already closed` | `Эта смена уже закрыта` |
| `Surplus +<x id="amount" equiv-text="amount"/>` | `Излишек +<x id="amount" equiv-text="amount"/>` |
| `Shortage −<x id="amount" equiv-text="amount"/>` | `Недостача −<x id="amount" equiv-text="amount"/>` |
| `Shift <x id="sequence" equiv-text="sequence"/> closed` | `Смена <x id="sequence" equiv-text="sequence"/> закрыта` |
| `Counted amount is required` | `Укажите пересчитанную сумму` |
| `Counted amount cannot be negative` | `Пересчитанная сумма не может быть отрицательной` |

The minus in `Shortage −` is U+2212 (copy it from `messages.xlf`); the Russian target uses the same U+2212. Use the ids and the exact `<x .../>` placeholder markup that `messages.xlf` shows (copy the source line character for character, the way the existing `Remaining: <x id="amount" equiv-text="amount"/>` unit is written in `messages.ru.xlf`); do not invent ids. If `messages.xlf` shows a different count of new units than 13, add a target for every unit that is new relative to the previous `messages.ru.xlf` and report the difference.

**Step 3:**

```bash
npm run i18n:check
```

It must print `OK: <n> units translated`. Then run `git diff --stat projects/shared/src/locale/messages.ru.xlf` and confirm only insertions (no deletions).
