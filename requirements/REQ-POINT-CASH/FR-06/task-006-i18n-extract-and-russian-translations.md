# Task 006: Extract i18n and add Russian targets for the operator Cash screen

> **Applied Skill:** AGENTS.md i18n Rules - `npm run i18n:extract` regenerates `projects/shared/src/locale/messages.xlf` (it writes only that file); every new `<trans-unit>` gets a Russian `<target>` in `projects/shared/src/locale/messages.ru.xlf` in the same change.

## 1. Objective

Only two NEW units exist in this FR. Everything else the screen shows is reused and already has a
Russian target (`No shift is running`, `The running shift could not be loaded`, `Close shift`,
`Cash can be collected only at an active point`, `This action is not available yet`, `Retry`,
`No working point assigned`, `Shift opening`, `Expected cash`, `Shift {sequence} · opened {time}`).

Existing units' targets MUST NOT change. The diff of `messages.ru.xlf` must be additions only (2 new `<trans-unit>` blocks, nothing modified or removed).

Requires tasks 001 and 005.

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf` - **Action:** Regenerated by `npm run i18n:extract`
* **File Path:** `projects/shared/src/locale/messages.ru.xlf` - **Action:** Modify Existing File

## 3. Code Implementation

**Step 1:**

```bash
npm run i18n:extract
```

**Step 2.** For each row, find the unit in `messages.xlf` by source text (the nav item's source is `Cash`; locate it by its `Operator bottom navigation` meaning in the `<note>` / by its `labels.ts` line number - NOT the plain `Cash` unit used by `PaymentMethodCash`) and add to `messages.ru.xlf`, directly before `</body>`:

```xml
      <trans-unit id="ID_FROM_MESSAGES_XLF" datatype="html">
        <source>SOURCE_COPIED_VERBATIM</source>
        <target>RUSSIAN_TEXT</target>
      </trans-unit>
```

| English source | Meaning | Russian target |
|---|---|---|
| `Cash` | `Operator bottom navigation` | `Касса` |
| `Hand in cash` | (none) | `Сдать наличные` |

Use the id that `messages.xlf` shows for each of these two units; do not invent ids. Do not touch the existing `Cash` -> `Наличные` unit.

**Step 3:**

```bash
npm run i18n:check
```

It must print `OK: <n> units translated`. Then run `git diff --stat projects/shared/src/locale/messages.ru.xlf` and confirm only insertions (no deletions).

## 4. Validation Steps

Execute the following commands to ensure this task was successful. Do NOT run the full application server.

```bash
npm run i18n:extract
npm run i18n:check
npx ng build operator --configuration development
```
