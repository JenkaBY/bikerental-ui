# Task 018: Extract i18n and add Russian targets for the point detail page

> **Applied Skill:** AGENTS.md i18n Rules - `npm run i18n:extract` regenerates `projects/shared/src/locale/messages.xlf`; every new `<trans-unit>` gets a Russian `<target>` in `projects/shared/src/locale/messages.ru.xlf` in the same change.

## 1. Objective

Regenerate the source catalog after FR-02 task-002 and add the Russian translations of the new
strings. Strings whose English text already exists (`Profile`, `Type`, `Customer`, `Amount`,
`From`, `To`, `Deposit`, `Withdrawal`, `Penalty`, `Adjustment`, `Transaction`) share the existing
unit and need nothing.

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf` - **Action:** Regenerated by `npm run i18n:extract`
* **File Path:** `projects/shared/src/locale/messages.ru.xlf` - **Action:** Modify Existing File

## 3. Code Implementation

**Step 1:**

```bash
npm run i18n:extract
```

**Step 2.** For each row, find the unit in `messages.xlf` by source text (and meaning, where given -
units with a meaning carry `<note priority="1" from="meaning">...</note>`), and add to
`messages.ru.xlf`, directly before `</body>`:

```xml
      <trans-unit id="ID_FROM_MESSAGES_XLF" datatype="html">
        <source>SOURCE_COPIED_VERBATIM</source>
        <target>RUSSIAN_TEXT</target>
      </trans-unit>
```

If `Position` or `Order` already has a Russian unit (same source, no meaning), keep the existing

**Step 3:**

```bash
npm run i18n:check
```

It must print `OK: <n> units translated`.
