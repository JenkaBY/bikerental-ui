# Task 014: Extract i18n messages and add Russian translations for FR-02

> **Applied Skill:** AGENTS.md *i18n Rules* - `projects/shared/src/locale/` is the only locale directory; `messages.xlf` is extractor output (never hand-edited); every new `<trans-unit>` must get a Russian `<target>` in the hand-maintained `messages.ru.xlf` in the same change. Same procedure as FR-01 Task 011.

## 1. Objective

Regenerate `messages.xlf` so it contains the new FR-02 strings from Task 007, then add a `<trans-unit>` with a Russian `<target>` to `messages.ru.xlf` for every new message id.

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf`
* **Action:** Regenerated by `npm run i18n:extract` (do NOT hand-edit)

* **File Path:** `projects/shared/src/locale/messages.ru.xlf`
* **Action:** Modify Existing File

## 3. Code Implementation

**Imports Required:** none.

**Code to Add/Replace:**

* **Location:** Step 1 — run the extractor from the repository root:

```bash
npm run i18n:extract
```

* **Location:** Step 2 — for EACH row of the table below, find the unit in `projects/shared/src/locale/messages.xlf`:
  * rows with a value in the "Custom id" column: Grep `messages.xlf` for `id="<custom id>"` (for example `id="pointDetailTabCash"`);
  * all other rows: Grep `messages.xlf` for the exact `<source>` text and copy its numeric `id`.

  Then Grep `projects/shared/src/locale/messages.ru.xlf` for that same `id="..."`:
  * if the id ALREADY exists in `messages.ru.xlf`, skip the row;
  * otherwise insert a new unit in `messages.ru.xlf` directly ABOVE the closing `</body>` tag, using exactly this shape (6-space indent for `<trans-unit>`, 8-space indent for `<source>` / `<target>`, matching the existing file):

```xml
      <trans-unit id="PASTE_ID_FROM_messages.xlf" datatype="html">
        <source>PASTE_SOURCE_FROM_messages.xlf</source>
        <target>RUSSIAN_TARGET_FROM_TABLE</target>
      </trans-unit>
```

  Copy `<source>` character-for-character from `messages.xlf`. Do NOT copy `<context-group>` or `<note>` elements (existing units in `messages.ru.xlf` carry only `<source>` and `<target>`).
