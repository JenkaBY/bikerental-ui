# Task 013: Extract i18n and add Russian targets for the Cash tab

> **Applied Skill:** AGENTS.md i18n Rules - `npm run i18n:extract` regenerates `projects/shared/src/locale/messages.xlf`; every new `<trans-unit>` gets a Russian `<target>` in `projects/shared/src/locale/messages.ru.xlf` in the same change.

## 1. Objective

Regenerate the source catalog after task-006 and add the Russian translations of the new strings.
`Cash collection`, `Rental payment`, `Deposit`, `Withdrawal`, `Penalty`, `Adjustment` and
`Movements could not be loaded` already exist and need nothing.

Requires task-006 (and every task that uses the labels).

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf` - **Action:** Regenerated by `npm run i18n:extract`
* **File Path:** `projects/shared/src/locale/messages.ru.xlf` - **Action:** Modify Existing File

## 3. Code Implementation

**Step 1:**

```bash
npm run i18n:extract
```

**Step 2.** For each row, find the unit in `messages.xlf` by source text and add to
`messages.ru.xlf`, directly before `</body>`:

```xml
      <trans-unit id="ID_FROM_MESSAGES_XLF" datatype="html">
        <source>SOURCE_COPIED_VERBATIM</source>
        <target>RUSSIAN_TEXT</target>
      </trans-unit>
```

| English source | Russian target |
|---|---|
| `Cash drawer` | `Касса` |
| `Terminal account` | `Счёт терминала` |
| `Shift opening` | `На начало смены` |
| `Expected cash` | `Ожидается в кассе` |
| `No shift is running` | `Смена не открыта` |
| `The running shift could not be loaded` | `Не удалось загрузить текущую смену` |
| `Shift cash movements` | `Кассовые движения смены` |
| `No cash movements in this shift` | `Нет кассовых движений за эту смену` |
| `Collect cash` | `Сдать в банк` |
| `Close shift` | `Закрыть смену` |
| `Record settlement` | `Зачислить в банк` |
| `Cash can be collected only at an active point` | `Инкассация возможна только в действующем пункте` |
| `Settlements cannot be recorded at a permanently closed point` | `Нельзя записать зачисление в навсегда закрытом пункте` |
| `This action is not available yet` | `Это действие пока недоступно` |
| `Show more` | `Показать ещё` |
| `Shift {sequence} · opened {time}` | `Смена {sequence} · открыта в {time}` |

For the last row the `<source>` contains two placeholder elements
(`<x id="sequence" .../>` and `<x id="time" .../>`) - copy the whole `<source>` content verbatim
and, in `<target>`, write the Russian words around the same two `<x .../>` elements (identical
attributes, same ids).

If a row's source text already has a Russian unit (same text, no meaning), keep the existing one and
do not add a duplicate id.

**Step 3:**

```bash
npm run i18n:check
```

It must print `OK: <n> units translated`.

## 4. Validation Steps

Execute the following commands to ensure this task was successful. Do NOT run the full application server.

```bash
npm run i18n:extract
npm run i18n:check
npx ng build admin --configuration development
npx ng build operator --configuration development
```
