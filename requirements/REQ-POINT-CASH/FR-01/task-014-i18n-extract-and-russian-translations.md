# Task 014: Extract i18n and add Russian targets for the points list

> **Applied Skill:** AGENTS.md i18n Rules - run `npm run i18n:extract` to regenerate `projects/shared/src/locale/messages.xlf` (never hand-edit it) and fill a Russian `<target>` for every new `<trans-unit>` in `projects/shared/src/locale/messages.ru.xlf` in the same change. An empty or missing target is a bug.

## 1. Objective

Regenerate the English source catalog after tasks 007 and 012, add the Russian translations of the
new FR-01 strings, and drop the Russian units of the two labels removed in task-012.

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf` - **Action:** Regenerated by `npm run i18n:extract` (do not edit by hand)
* **File Path:** `projects/shared/src/locale/messages.ru.xlf` - **Action:** Modify Existing File

## 3. Code Implementation

**Imports Required:** none.

**Step 1 - extract:**

```bash
npm run i18n:extract
```

**Step 2 - add Russian units.** For each row below, find the `<trans-unit>` in
`messages.xlf` whose `<source>` matches the English column (units with a meaning carry
`<note priority="1" from="meaning">` in `messages.xlf`; match on source + meaning). Copy its `id`
and its exact `<source>` element (including any `<x id="..." equiv-text="..."/>` placeholders)
into a new unit in `messages.ru.xlf`, placed directly before the closing `</body>` tag, in this
exact shape (no `context-group`, matching the existing units in the ru file):

```xml
      <trans-unit id="ID_FROM_MESSAGES_XLF" datatype="html">
        <source>SOURCE_COPIED_VERBATIM</source>
        <target>RUSSIAN_TEXT</target>
      </trans-unit>
```

In the Russian target, reuse the very same `<x .../>` placeholder elements as the source, at the
positions shown with `{...}` below.

| English source (meaning) | Russian target |
|---|---|
| `Point` (meaning `Points table column header`) | `Точка` |
| `Cash in drawer` | `Наличные в кассе` |
| `Terminal` | `Терминал` |
| `Cash across all drawers` | `Наличные во всех кассах` |
| `On terminal accounts` | `На счетах терминалов` |
| `Show closed points` | `Показывать закрытые точки` |
| `Rental points could not be loaded` | `Не удалось загрузить пункты проката` |
| `Deposited to bank in {month}` | `Зачислено в банк за {month}` |
| `Collections {collected} · Terminal settlements {terminalSettled}` | `Инкассации {collected} · Расчёты по терминалам {terminalSettled}` |
| `Closed hidden: {count}` | `Скрыто закрытых: {count}` |

`Status` already has a Russian unit (`Статус`) and needs nothing.

**Step 3 - remove stale Russian units.** In `messages.ru.xlf`, delete the whole `<trans-unit>`
whose `<source>` is `Rental points list`, and the whole `<trans-unit>` whose `<source>` is
`Select a rental point or create a new one` (both labels were removed in task-012 and no longer
exist in `messages.xlf`). Before deleting, confirm each source text no longer appears in
`messages.xlf`; if it still does, keep the unit.

**Step 4 - verify every unit is translated:**

```bash
npm run i18n:check
```

It must print `OK: <n> units translated`.

## 4. Validation Steps

Execute the following commands to ensure this task was successful. Do NOT run the full application server.

```bash
npm run i18n:extract
npm run i18n:check
npx ng build admin --configuration development
npx ng build operator --configuration development
```
