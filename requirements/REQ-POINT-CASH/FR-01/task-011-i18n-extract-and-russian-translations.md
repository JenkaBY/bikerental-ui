# Task 011: Extract i18n messages and add Russian translations

> **Applied Skill:** AGENTS.md *i18n Rules* - `projects/shared/src/locale/` is the only locale directory; `messages.xlf` is extractor output (never hand-edited); every new `<trans-unit>` must get a Russian `<target>` in the hand-maintained `messages.ru.xlf` in the same change.

## 1. Objective

Regenerate `messages.xlf` so it contains the new FR-01 strings from Task 005, then add a `<trans-unit>` with a Russian `<target>` to `messages.ru.xlf` for every new message id.

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf`
* **Action:** Regenerated by `npm run i18n:extract` (do NOT hand-edit)

* **File Path:** `projects/shared/src/locale/messages.ru.xlf`
* **Action:** Modify Existing File

## 3. Code Implementation

**Imports Required:** none.

**Code to Add/Replace:**

* **Location:** Step 1 — run the extractor from the repository root:

```bash
npm run i18n:extract
```

* **Location:** Step 2 — for EACH row of the table below, find the unit in `projects/shared/src/locale/messages.xlf`:

```xml

        <source>PASTE_SOURCE_FROM_messages.xlf</source>
```
