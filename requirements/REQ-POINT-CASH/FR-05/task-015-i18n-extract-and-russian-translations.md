# Task 015: Extract i18n and add Russian targets for the money-move dialogs

> **Applied Skill:** AGENTS.md i18n Rules - `npm run i18n:extract` regenerates `projects/shared/src/locale/messages.xlf` (never hand-edited); every new `<trans-unit>` gets a Russian `<target>` in `projects/shared/src/locale/messages.ru.xlf` in the same change. `npm run i18n:check` is the gate.

## 1. Objective

Regenerate the source catalog after tasks 005, 007, 008 and add the Russian translations of every NEW unit. Terminology: "пункт" for point; the buttons keep FR-03's wording ("Сдать в банк" = Collect cash, "Зачислить в банк" = Record settlement).

**HARD RULE - do not change any EXISTING unit.** A previous FR's fixer overwrote an existing target because it had the same English source as a new label. If a row's English source already has a `<trans-unit>` in `messages.ru.xlf`, **leave that unit exactly as it is and add nothing**. Never edit a `<target>` that already exists, and never delete or reorder existing units. Meaning-prefixed labels (`From`, `To`, `All`) have their own new ids; the old period-filter units `From` -> `С`, `To` -> `По`, `All` -> `Все` stay untouched.

Requires tasks 005, 007, 008, 012, 013 (every task that uses a label).

## 2. File to Modify / Create

* **File Path:** `projects/shared/src/locale/messages.xlf` - **Action:** Regenerated by `npm run i18n:extract`
* **File Path:** `projects/shared/src/locale/messages.ru.xlf` - **Action:** Modify Existing File (append new units only)

**Step 1:**

